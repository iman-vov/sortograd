# Сортоград

Затишна ізометрична гра для планшета в браузері: містечко розсипалось на кольорові цеглинки — збирай їх тапами, неси на станцію сортування, відбудовуй будинок за будинком і прокачуй дерево покращень.

**Грати:** https://iman-vov.github.io/sortograd/

## Що вже є (прототип v3)

- 3D-ізометрія на Three.js, один файл `index.html`, без збірки
- 6 матеріалів цеглин (цегла, скло, пластик, метал, камінь, дерево): кожен береться за свій час, тож будинки виходять різними
- Потрібні для вибраного будинку цеглини одразу йдуть у сумку для будови; решта сортується на станції, а будує гравець власноруч: тап по жовтих місцях креслення або кнопка «Покласти». Над будівлею видно, що їй потрібно
- 6 тематичних кварталів (весна, пекарі, парк, осінь, порт, зима) з різною формою поля, далі — процедурні
- Дерево покращень: 56 вузлів, розвилки, синергії, майстерність гілок, ідеї, віхи, замовлення
- Помічники (пес, роботи, вакуум, дрон) приносять цеглини лише на станцію, тож будувати все одно тобі
- Розслаблювальна генеративна музика: 5 треків, що чергуються; гучність музики й звуків окремо в меню
- Вступ і навчання на першому рівні
- Мови: українська, English, Deutsch
- Гра вдвох по Wi‑Fi: один збирає, інший будує

## Гра вдвох

Обидва пристрої відкривають https://iman-vov.github.io/sortograd/ в одній мережі Wi‑Fi. Один гравець натискає «👫 Гра вдвох» → «Створити кімнату» і отримує код із 4 цифр, другий вводить цей код. Прогрес зберігається на пристрої того, хто створив кімнату.

**На головний екран:** Safari → «Поділитися» → «На початковий екран». Гра відкриється на весь екран.

## Структура

```
index.html               гра (Three.js з CDN через importmap)
manifest.webmanifest     встановлення як застосунок
icons/                   іконки
docs/GDD.md              повний дизайн-документ і ТЗ (механіки, дерево, стек, етапи, промпти для ChatGPT і Meshy)
```

## Локальний запуск

Будь-який статичний сервер, наприклад:

```bash
npx serve .
# або
python3 -m http.server 8080
```

Тест на планшеті в тій самій мережі: відкрити `http://<IP-комп'ютера>:8080`.
