# Сортоград

Затишна ізометрична гра для планшета в браузері: містечко розсипалось на кольорові цеглинки — збирай їх тапами, неси на станцію сортування, відбудовуй будинок за будинком і прокачуй дерево покращень.

**Грати:** https://iman-vov.github.io/sortograd/

## Що вже є (прототип)

- 3D-ізометрія на Three.js, один файл `index.html`, без збірки
- Тап-збір із радіусом дотягу, чергою тапів і ходьбою по A*
- Станція сортування з ящиками за кольорами, будівлі по шарах із «привидами»-кресленнями
- Дерево покращень: 6 гілок × 5 тирів, розвилки, синергії, майстерність гілок, ідеї та віхи
- Квартали з наростаючою складністю (1, 2 — ручні, 3+ — процедурні)
- Помічники: пес, роботи, вакуумна станція, автобудівник, нічна зміна
- Звуки (WebAudio), частинки, збереження в браузері

## Керування

| Планшет / телефон | ПК |
|---|---|
| Тап по цеглині — зібрати | Клік |
| Тап по землі — йти | Клік або WASD |
| Два пальці — масштаб | Колесо миші |
| Кнопка ⟳ — повернути камеру | Q / E |
| Тап по будівлі — вибрати креслення | Клік |

**На головний екран:** Safari → «Поділитися» → «На початковий екран». Гра відкриється на весь екран.

## Структура

```
index.html               гра (Three.js з CDN через importmap)
manifest.webmanifest     встановлення як застосунок
icons/                   іконки
docs/GDD.md              повний дизайн-документ і ТЗ (механіки, дерево, стек, етапи, промпти для ChatGPT і Meshy)
```

## Локальний запуск

Будь-який статичний сервер, наприклад:

```bash
npx serve .
# або
python3 -m http.server 8080
```

Тест на планшеті в тій самій мережі: відкрити `http://<IP-комп'ютера>:8080`.
